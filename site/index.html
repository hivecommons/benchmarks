Methodology

How these numbers are computed
  • Unit. One record = one unit of agent work on one pull request, exported from a hive's signed per-PR evidence bundle: agent-authored (the agent opened the PR) or agent review (the swarm reviewed someone's PR; the model shown is the majority reviewer model). Schema: schema/result.schema.json.
  • Backfill. Records with exporter: backfill-from-cluster were converted from existing evidence by scripts/convert-evidence.py; they carry no per-PR cost (hive meters cost per agent/model, not per PR) and sandbox_runtime: none because those hives ran agents in-process. task.kind is unknown unless the agent name says otherwise.
  • Median time to merge is read from a 12-bucket log-scale histogram, so it is a bucket midpoint, not an exact value.
  • Merge rate = merged ÷ records with pr_opened. CI green first try = ci_green_first_try true ÷ records where CI was captured (nulls excluded). Cost / merged PR = Σ cost.usd over the group ÷ merged PRs in the group; records without cost are excluded from the numerator and the denominator.
  • Intervals. Every rate shows n and a 95% Wilson score interval. Groups with n < 10 are shown as not reported, the same rule hivecommons/hive uses for its monthly outcome benchmark.
  • Cost basis. USD is estimated from public price tables by the hive token collector (GET /api/cost), or apportioned from per-agent totals. It is not a bill. Records say which (cost.basis).
  • Synthetic records (synthetic: true) are excluded unless you tick the box. They exist so the page renders before real exports land.
  • Privacy. Every hive publishes anonymized records by default (opt-out: benchmarks.publish: false). Repository and org names appear only for public repositories (repo_consent); private repos stay anonymous. No logins, prompts, finding text or code are published. See GOVERNANCE.md.
  • Confounders. Models are not assigned to tasks at random: harder tasks go to bigger models, review agents never open PRs, and hives differ in ACMM policy. Filter by task kind and ACMM level before comparing; treat cross-model differences as observational.
