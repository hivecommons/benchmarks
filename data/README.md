# Data

Benchmark records live here as JSON, one record per file or an array per file, under
`data/<org>/<yyyy-mm>/*.json`. Every file must validate against
[`schema/result.schema.json`](../schema/result.schema.json).

* `data/fleet/<hive_hash>/<yyyy-mm>.json` — real records, one directory per hive (anonymous hash),
  one file per month. Written by `scripts/backfill-from-cluster.sh` today and by the hub publisher
  once hivecommons/hive#17694 ships. Record ids are stable, so re-runs overwrite in place.
* `data/sample/` — **synthetic** hand-written records (`"synthetic": true`) so the site renders
  before any real export exists. The site excludes them from leaderboards.
* `data/index.json` — generated by `scripts/build-index.sh`; do not edit by hand.

Data in this directory is licensed CC-BY-4.0 (see `LICENSE-DATA`). Repository names appear only for
public repositories (`repo_consent: true`); records never contain GitHub logins, prompts, finding
text or code excerpts (see `GOVERNANCE.md`).
