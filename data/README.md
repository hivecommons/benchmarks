# Data

Benchmark records live here as JSON, one record per file or an array per file, under
`data/<org>/<yyyy-mm>/*.json`. Every file must validate against
[`schema/result.schema.json`](../schema/result.schema.json).

* `data/fleet/<hive_hash>/<yyyy-mm>.json` — real records, one directory per hive (anonymous hash),
  one file per month. Written by the hub publisher (hivecommons/hive#17716, RFC #17694); hives that
  have not upgraded yet are covered by `scripts/backfill-from-cluster.sh`. Record ids are stable, so
  re-runs overwrite in place.
* `data/sample/` — **synthetic** hand-written records (`"synthetic": true`) so the site renders
  before any real export exists. The site excludes them from leaderboards.
* `data/index.json` — generated by `scripts/build-index.sh`; do not edit by hand.

Data in this directory is licensed CC-BY-4.0 (see `LICENSE-DATA`). Repository names and
`source.org` are permitted only with `task.repo_consent: true`; `source.org` is derived from
the owner of the consented `bundle.repo` in hive's evidence bundle (see
[`docs/INVENTORY.md`](../docs/INVENTORY.md)). Records never contain GitHub logins, prompts,
finding text or code excerpts (see `GOVERNANCE.md`).

The current record schema version is `2`; version `1` records remain accepted if they meet
the same privacy constraint.
